EnjoyTrip — 원석 UI와 미르 여행 흐름의 선택적 통합

1. js/config.js가 없으면 js/config.example.js를 복사하세요.
   기존 config.js와 개인 키가 있으면 덮어쓰지 마세요.
   references/ssafy-kakao의 수업 키는 복사하지 마세요.
2. 본인의 Kakao JavaScript 키와 TourAPI 서비스 키를 설정하세요.
   실제 TourAPI 활용신청과 Kakao Maps 사용 설정이 필요합니다.
3. VS Code Live Server가 localhost:5500에서 실행 중이면 그대로 사용하세요.
   서버가 없으면 프로젝트 루트에서 실행:
   python3 -m http.server 5500 --bind 127.0.0.1
4. http://localhost:5500 으로 접속하세요.
   현재 실연동을 확인한 주소이며, Kakao 허용 도메인에도 동일 주소가 필요합니다.
   호스트·포트를 변경하면 별도 도메인 등록과 저장소가 적용됩니다.
5. 회원가입 → 로그인 → 검색어·여행 무드·상세 필터로 검색 → 유형별 지도 핀 확인
   → 여행계획 담기 → 순서·날짜·예산·메모 저장
6. 실제 다녀온 뒤 “다녀왔어요”에서 지역·날짜를 확인하고 기록하세요.
   여행 여권의 지역 스탬프·통계에 반영됩니다.
   검색·계획 저장·HotPlace 등록만으로는 방문 처리되지 않습니다.
7. HotPlace 등록 모달에서 관광지를 검색해 연결하거나 직접 위치를 정하세요.
   사진 URL 또는 파일을 추가할 수 있고 파일은 브라우저에서 JPEG로 압축됩니다.
   “나만의 발견” 저장과 방문 완료 기록은 별도입니다.
8. MyPage에서 내 계획·방문·HotPlace 통계를 보고 JSON 백업을 받을 수 있습니다.
   백업에는 현재 계정의 자료만 포함하며 비밀번호·salt·해시는 제외합니다.

홈·회원·기존 로컬 기록은 키 없이도 사용할 수 있습니다.
실제 관광 검색과 지도에는 유효한 개인 키가 필요합니다.
새 방문 기록에는 실제 API 또는 이전에 보관한 지역 목록이 필요합니다.
사이트 실행 자체에는 npm 설치가 필요 없습니다.
