# enjoytrip

SSAFY 16기 Web(Front) PJT 명세서의 필수 기능과 여행 계획, 핫플레이스, 커뮤니티 기능을 구현한 국내 여행 웹서비스입니다. 기존 랜딩 디자인을 유지하고 기능별 페이지를 연결했습니다.

## 실행

Node.js 20 이상이 필요합니다. 현재 검증 환경은 Node.js 24입니다. 운영 서버는 Node.js 기본 모듈만 사용합니다.

```powershell
npm.cmd start
```

브라우저에서 **http://localhost:3000**을 엽니다. HTML을 파일로 직접 열거나 다른 Live Server로 실행하지 마세요. 관광정보 API 프록시와 브라우저 암호화 기능이 localhost 서버에서 동작합니다.

개발할 때는 `npm.cmd run dev`로 변경을 자동 반영할 수 있습니다. 이미 서버가 실행 중이면 수정한 서버 코드가 반영되도록 다시 실행해 주세요. PowerShell 실행 정책으로 `npm`이 차단되는 환경에서는 `npm.cmd`를 사용합니다.

## API 설정

프로젝트 루트 `.env`에 제공받은 키를 설정했습니다. `.env`는 Git에 포함되지 않습니다. 다른 환경에서는 `backend/.env.example`을 프로젝트 루트 `.env`로 복사해 값을 입력합니다.

```dotenv
PORT=3000
KAKAO_MAP_KEY=카카오_JavaScript_키
TOUR_API_KEY=공공데이터포털_Decoding_키
TOUR_API_BASE=https://apis.data.go.kr/B551011/KorService2
```

공공데이터 키는 서버에서만 사용합니다. 브라우저에는 공개용 카카오 지도 JavaScript 키만 전달합니다.

### 카카오 지도 설정

카카오 개발자 콘솔에서 다음을 설정해야 합니다.

1. 키가 **JavaScript 키**인지 확인합니다.
2. 해당 앱의 **카카오맵 API 사용**을 활성화합니다.
3. JavaScript SDK 도메인에 **http://localhost:3000**을 등록합니다.
4. `127.0.0.1` 또는 다른 포트를 사용하면 해당 origin도 등록합니다.

실제 화면 검증에서 관광 API는 정상 동작했지만 카카오가 `domain mismatched! caller=http://localhost:3000`을 반환했습니다. 제공한 앱의 JavaScript SDK 도메인에 `http://localhost:3000`을 등록해야 합니다. 콘솔 등록은 앱 소유자가 완료해야 합니다. 실패하면 화면에 이유와 현재 도메인을 표시하며 다른 기능은 계속 사용할 수 있습니다.

공식 문서: [카카오 지도 시작하기](https://apis.map.kakao.com/web/guide/), [카카오맵 사용 설정](https://developers.kakao.com/docs/en/kakaomap/common), [한국관광공사 국문 관광정보 서비스](https://www.data.go.kr/data/15101578/openapi.do).

## 사용 순서

1. 메인 화면의 **관광지 둘러보기**를 누릅니다.
2. **로그인 → 회원가입**에서 아이디, 이름, 이메일, 비밀번호와 보안 질문 답변을 등록합니다.
3. 관광지 탐색에서 지역/유형/검색어로 조회하고 장소 이름을 눌러 상세정보를 확인합니다.
4. **찜하기**로 저장하거나 **여행에 담기**로 현재 여행 계획에 추가합니다.
5. 여행 계획에서 방문 순서, 일차, 시간, 경비, 메모를 입력하고 **계획 저장**을 누릅니다. 지도 점선은 장소를 연결한 선으로 실제 도로 경로가 아닙니다. 실제 이동은 장소별 카카오 길찾기를 사용합니다.
6. 핫플레이스 등록 창에서 지역·유형·이름으로 관광지를 검색하고 선택하면 장소 이름·주소·유형·지도 위치가 자동으로 채워집니다. 관광지 상세 화면의 **이 장소 핫플레이스 등록**으로도 바로 연결됩니다. 직접 찍은 사진, 방문일, 소개를 작성해 저장합니다. 직접 장소를 입력하거나 주소 검색/지도 클릭으로 위치를 지정할 수도 있습니다.
7. 커뮤니티에서 공지사항·공유게시판을 선택하고 글을 작성합니다. 수정·삭제는 작성자에게만 표시됩니다.
8. 우측 회원 이름을 눌러 마이페이지에서 정보 수정, 데이터 백업, 로그아웃, 탈퇴를 할 수 있습니다.

## localStorage 데이터 구조

DB 키는 `enjoytrip.db.v1`, 로그인 키는 `enjoytrip.session.v1`입니다.

```text
enjoytrip.db.v1
├── version: 1
├── users       회원 정보, salt, 비밀번호/보안답변 해시
├── favorites   userId별 찜한 관광지
├── plans       userId별 여행과 장소·일정·비용·메모
├── hotplaces   작성자, 사진, 위치, 방문일, 소개
└── posts       게시판 종류, 작성자, 제목, 내용, 조회수
```

비밀번호와 보안답변은 평문으로 저장하지 않고 PBKDF2-SHA256(120,000회)과 회원별 salt로 해시합니다. 탈퇴 시 해당 회원 데이터만 삭제합니다. 게시글과 API 텍스트는 HTML로 실행하지 않고 이스케이프해서 표시합니다. 저장 공간이 부족하면 오류를 표시하고 기존 저장 데이터를 유지합니다.

사진은 JPEG/PNG/WebP, 최대 5MB 입력을 받고 긴 변을 최대 1000px로 축소해 JPEG로 저장합니다. 저장하는 사진 한 장은 약 700KB 이하로 제한합니다.

프론트엔드 과제용 로컬 회원 시스템이므로 브라우저 개발자 도구로 데이터를 변경할 수 있으며 다른 기기나 사용자 브라우저와 동기화되지 않습니다. 실서비스의 서버 인증/인가를 대체하지 않습니다. 브라우저 저장소를 삭제하면 회원·여행 데이터도 삭제되므로 마이페이지에서 필요한 데이터를 백업해 주세요.

## 서버 API

| 경로 | 용도 |
| --- | --- |
| `GET /api/config` | 공개 가능한 지도 키와 관광 API 설정 여부 |
| `GET /api/tour/areas?areaCode=1` | 전국 시·도 또는 선택 지역의 시·군·구 |
| `GET /api/tour/list` | 지역·유형·검색어·페이지별 관광정보 |
| `GET /api/tour/detail?contentId=...&contentTypeId=...` | 공통 소개, 이용 정보, 추가 사진 |
| `GET /api/health` | 서버 상태 확인 |

TourAPI 호출 결과는 서버 메모리에 5분간 캐시합니다. 회원·여행 DB는 서버에 저장하지 않습니다. 공공데이터 오류가 발생하면 재시도 가능한 오류 화면을 표시합니다.

## 검증

테스트 개발 의존성 설치 후 다음을 실행합니다.

```powershell
npm.cmd install
npm.cmd test
npm.cmd run test:api
```

자동 검증 결과:

- 회원가입, 중복 검증, 잘못된/정상 로그인, 비밀번호 재설정
- 회원 조회·수정·탈퇴, 회원별 데이터 분리, 작성자 수정/삭제 권한
- 찜과 여행지 추가, 일정 정렬·비용 수정·저장·장소 삭제
- 핫플레이스 사진 검증·조회·수정, 공지/공유게시판 작성·조회·수정·검색
- 저장 공간 부족 시 기존 데이터 보존, 게시글 HTML 실행 방지
- 실제 TourAPI의 17개 지역, 시·군·구, 8개 콘텐츠 유형, 키워드, 상세정보 응답
- UTF-8 한글 소스와 PC/모바일 화면 캡처 확인

`test:api`는 임시 포트 3197에서 검증 서버를 띄웠다가 종료하며 실제 공공데이터 API를 호출합니다.

## 파일 구성

```text
frontend/
  index.html              기존 메인 랜딩
  explore.html            관광지 검색과 지도
  planner.html            여행 계획
  hotplace.html           핫플레이스
  community.html          공지사항 / 공유게시판
  mypage.html             회원 관리
  assets/js/              ES 모듈, localStorage, API, 지도, 회원 기능
  assets/css/             랜딩 스타일 / 서비스 스타일
  assets/vendor/          로컬 Bootstrap 5.3.8 CSS
backend/src/
  server.js               Node.js 정적 서버
  tour-api.js             공공데이터 프록시 / 환경 설정
tests/                    프론트 모듈과 DOM을 검증하는 7개 테스트
docs/screenshots/         실행 화면 캡처
```

Bootstrap의 그리드, 반응형 컬럼, 폼, 테이블 유틸리티를 활용했습니다. 모달은 HTML `<dialog>`와 JavaScript로 구현했습니다. Bootstrap CSS는 프로젝트에 포함되어 있으며 Pretendard, 카카오 지도 SDK, 실제 관광 사진은 네트워크 연결이 필요합니다.
